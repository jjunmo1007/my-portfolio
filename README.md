# 송준모 자기소개 웹사이트

친구와 선생님에게 나의 관심사, 잘하는 것, 배우고 싶은 것, 해본 활동과 앞으로의 목표를 소개하는 한국어 반응형 웹사이트입니다. React와 Vite로 만들었습니다.

## 실행하기

1. Node.js 24 LTS를 설치합니다.
2. 프로젝트 폴더에서 다음 명령을 실행합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 엽니다. 개발 서버는 `Ctrl + C`로 종료합니다.

## 내용 수정하기

- `src/App.jsx`: 자기소개 문구와 섹션 내용
- `src/App.css`: 페이지 레이아웃, 반응형 규칙, 카드 스타일
- `src/index.css`: 공통 색상과 기본 스타일
- `public/`: 나중에 추가할 이미지 등 정적 파일

학교 과제나 발표의 실제 이름·설명·사진은 준비되면 `src/App.jsx`의 활동 영역에 추가할 수 있습니다. 본인에 관한 내용만 적고 전화번호, 주소, 생년월일 등 개인정보는 게시하지 마세요.

## 확인 명령

```sh
npm run lint
npm run build
```

`npm run build`는 배포용 파일을 `dist` 폴더에 만듭니다.
